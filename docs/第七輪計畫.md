# 花椰菜相機：第七輪計畫

寫於 2026-11-24。多米這次提了七件事，第 1 件是問題，後六件是要做的功能。還沒動程式，等多米點頭。

## 一、之前規劃了還沒做完的

規劃文件、規格書、README、三個舊對話都翻過。

### 完全沒做

| 項目 | 寫在哪 | 現況 |
|---|---|---|
| 畫面太暗時提示靠近光源 | 規格書 06-B | 程式裡沒有。併進這輪的一鍵優化 |
| 字幕直接燒進影片 | 需求缺口 3 | 只做到輸出 SRT 檔 |
| 會即時反應的聆聽者、多位聆聽者 | 規格書 P2 | 現在是五支預錄短片，原訂等你覺得短片有用再投資 |
| 一張發佈憑證給雲端重複用 | 2026-11-15 對話 | 沒做。每次打包都建新憑證，滿了會再卡一次 |
| 頂部小窗蓋到頭像框上緣 | QC-0005 交接 | 沒做 |
| 找三個沒拍過口播的人測分段錄影 | 需求缺口 1 | 沒做，這件要你找人 |

### 做了，還沒在你手機上驗過

- 語音跟隨：錄出來的聲音正不正常、唸過的字有沒有變綠、跟不跟得上
- 頭像框：坐近坐遠貼不貼頭
- 換模式、換擺法還會不會卡、畫面會不會黑
- 分段接片：聲音和畫面有沒有對上，頭尾有沒有切到字
- SRT 字幕的時間準不準
- 橫式錄影：兩個橫放方向都要試
- 音量鍵開始、停止錄影
- 陪伴模式：點頭的頻率、三種新擺法要留哪幾種
- 4K／60 長時間錄影會不會燙

### 濾鏡這件事

舊對話和文件裡找不到「一鍵優化」的討論。找得到的剛好相反：規格書寫「V1 不做美顏、磨皮、濾鏡」，需求缺口文件也寫不做美顏濾鏡。這輪照你現在說的改。腳本列表也一樣，規格書原本寫不做腳本資料庫，這輪改成要做。

## 二、六個功能怎麼做

### 1. 草稿字放大、腳本列表

- 字：圖 1 是 19 點，圖 2 量起來約 21 到 22 點。改成 22 點，跟著系統字級放大，再加「A−／A＋」讓你自己調。
- 列表：按「稿件」先進列表。每列有標題、兩行內文、字數、最後修改時間，正在用的那篇標「使用中」。
- 可以新增、改名、複製、拖曳排序、左滑刪除、從「檔案」匯入 txt 和 md、分享出去。刪除前會問。
- 編輯頁下方固定一列：字數和預估時長、「使用這篇」。「清空」收進選單，現在放左上角太容易誤觸。
- 你現在手機上那篇稿會自動變成列表第一篇。
- 不加底部分頁。打開 app 一樣直接是相機。
- 顏色用花椰菜相機原本的深色和藕荷色，排法參考圖 2、圖 3。

### 2. 一鍵優化

參數在下一節。做法有三種，要你選。

### 3. 防抖

- 設定裡加「防抖」：關、標準、加強。手機前鏡頭不支援的選項不顯示。預設關。
- 開防抖通常會裁掉畫面外圍一圈，取景變窄。預覽要跟著裁，不然頭對在框裡、錄出來會跑位，這點只能真機驗。
- 手機架在腳架上用不到，拿在手上邊走邊錄才有感。

### 4. 主畫面開關語音跟隨

- 我的理解是「提詞跟著我的聲音走」那個開關，放到主畫面狀態列，一顆波形按鈕，亮著就是開。
- 錄影前、錄影中都能按。錄影中關掉，提詞改回固定速度；再打開，從現在的位置接著跟。
- 錄影前就是關的，錄影中不能打開，因為錄到一半接上音訊會中斷錄影。

### 5. 跳轉與藍牙控制

- 主畫面提詞區右側加上下兩顆跳轉鍵。點提詞裡任何一行，也會跳到那一行。
- 跳完之後語音跟隨從新位置接著聽。現在它只會往前，講錯想退回去重唸會卡住，這次一起修。
- 設定加「藍牙控制」：
  - 按鍵測試：按一下踏板，畫面顯示收到哪個鍵、會做什麼。
  - 往下：↓ → PageDown。往上：↑ ← PageUp。暫停或繼續：空白鍵、Enter、句號。跟你的 teleprompter 一樣。
  - C 開關語音跟隨，M 切換「逐段」和「逐行」。
  - 每個動作可以自己指定按鍵，另外加一個「開始／停止錄影」。
- 設定加「分段錄影」開關，預設開，跟現在一樣。關掉就整篇一鏡到底，跳轉才能跨段。開著的時候，沒在錄是換段，錄影中是在這一段裡逐行跳。
- 限制：只會送音量鍵的自拍遙控器不能拿來跳轉，音量鍵已經給錄影用了。踏板和翻頁器送的是鍵盤按鍵，可以用。

### 6. 構圖輔助線

- 設定改成三選一：關、頭像框、九宮格。主畫面也放一顆，按一下輪著切。
- 頭像框保留大小調整，線的濃淡兩種都能調。
- 頭像框在提詞開始後照舊淡出。九宮格留著，濃淡降一半。兩種都不會錄進影片。

## 三、一鍵優化的參數

按一下，系統讀目前的畫面，算出每一項該調多少。每一項都能自己再拉，也能整組還原。

| 參數 | 系統看什麼 | 怎麼調 |
|---|---|---|
| 測光和對焦位置 | 臉在哪裡 | 移到臉上 |
| 曝光 | 臉的平均亮度、過曝的面積 | 臉太暗加、過曝減 |
| 色溫 | 臉的顏色偏藍或偏黃 | 往正常膚色拉回 |
| 色調 | 臉的顏色偏綠或偏紅 | 往正常膚色拉回 |
| 亮部 | 窗戶、燈有沒有死白 | 壓回來 |
| 暗部 | 頭髮、衣服有沒有黑成一塊 | 提亮 |
| 對比 | 整張亮度分布太平或太硬 | 拉開或放軟 |
| 自然飽和度 | 整張顏色濃度 | 補淡的顏色，膚色少動 |
| 降噪 | 感光度高不高 | 暗的時候才開 |
| 銳利 | 感光度和解析度 | 輕微，降噪開時減少 |
| 柔膚 | 不判斷 | 一鍵不會動它，想要自己拉 |

調到極限臉還是太暗，就顯示「請靠近光源」。這就是規格書裡欠的那一項。

### 三種做法

| | A 兩段式 | B 全部即時（多米 2026-11-24 選這個） | C 雲端 AI 判斷 |
|---|---|---|---|
| 怎麼運作 | 測光、曝光、色溫、色調在拍之前直接調鏡頭；其他項目錄完套上去，完成頁可以按住比對前後 | 每一格畫面即時處理，預覽和錄出來一樣 | 拍一張上傳，AI 回傳數值，再用 A 或 B 套 |
| 好處 | 錄影管線不動，原檔留著，隨時能還原 | 錄之前就看到最後的樣子 | 判斷可能比規則細 |
| 代價 | 後半段的效果錄完才看得到，存檔要多等一下 | 錄影核心要整個換掉，接片、語音跟隨、聲音都要重驗，4K 容易燙 | 要後端、每按一次付費、臉部畫面要上傳，違反「不上傳相機畫面」 |

多米選 B。判斷全在手機上算，不花錢、不連網。

## 四、順序

1. 腳本列表、字放大
2. 構圖輔助線、主畫面語音開關、防抖
3. 跳轉、藍牙控制、分段錄影開關
4. 一鍵優化
5. 頂部小窗蓋到頭像框，順手修

全部在新分支做，雲端編譯和 limrun 模擬器驗過再交。不推 main、不發 TestFlight，等你說要發。

模擬器驗不到防抖、真鏡頭的曝光色溫、藍牙踏板、語音跟隨，這四樣要你真機看。

這輪不做：字幕燒進影片、會即時反應的聆聽者、發佈憑證共用。
