# 花椰菜相機：客群還沒被滿足的需求，和接下來該做的功能

寫於 2026-11-15，對照 `spec-v1.1.html` 和第一輪的程式碼。
這份是我的判斷，沒有訪談資料撐腰，每一條都標了要怎麼驗證。

## 先講結論

第二輪我建議先不做陪伴模式，改做「分段錄影」。

規格書把客群的痛點排成：不會構圖、不會背稿、怕鏡頭。第一輪把前兩個做掉了。但我把一個新手錄一支口播的過程從頭走一遍，卡最久的地方都在按下錄影鍵之後：講錯一句整支重來、稿子捲太快追不上、錄完還要自己上字幕。這三件事現在的 app 都沒碰。

陪伴模式要先拍一組聆聽者短片，成本高，規格書自己也寫了效果還沒驗證。分段錄影不用任何素材，用現有的錄影管線就能做，而且「講錯重來」是每個新手每一次錄都會撞到的事。

## 新手錄一支口播，時間花在哪

拿一個講師要錄 2 分鐘的短影音來走一遍：

| 階段 | 他在做什麼 | 現在的 app 有沒有幫到 |
|---|---|---|
| 準備 | 在 Notion 或備忘錄寫稿，貼進來 | 有，整篇貼上 |
| 準備 | 想知道這篇稿講完是幾分鐘、會不會超過平台上限 | 沒有 |
| 架設 | 手機架好，對位置，確認收音 | 有，頭像框、臉部定位、收音檢查 |
| 架設 | 手機架在一臂之外，要走過去按錄影再走回來 | 只有倒數 |
| 錄影 | 照著提詞講 | 有，但速度是固定的 |
| 錄影 | 講到 1 分 40 秒吃螺絲 | 沒有，只能整支重錄 |
| 收尾 | 剪掉開頭走回定位、結尾伸手按停的那幾秒 | 沒有 |
| 收尾 | 上字幕 | 沒有 |

表裡「沒有」的那幾格，就是下面六個缺口。

## 六個缺口

### 1. 講錯一句，整支重來

現在的流程是一鏡到底。2 分鐘的稿，新手很少一次講完，錯在第 100 秒就是前面 100 秒白講。重來三次之後人會開始煩躁，越煩越錯，最後那支影片就不錄了。

做法：稿件用空行分段，一段錄一次。這段講壞了只重錄這段，全部錄完 app 把各段接成一支影片存進相簿。接片用 `AVMutableComposition`，不用自己寫編碼。

這個功能還順手解掉另一件事：每段都很短，提詞一次只顯示一段，人比較不會有「在唸一整面牆的字」的感覺。

規格書把分段錄影放在 P2。我覺得該提到最前面。

驗證方式：找三個沒拍過口播的人，各錄同一篇 2 分鐘的稿，一半用一鏡到底、一半用分段，看誰錄得完、花多久。

### 2. 稿子不等人

提詞現在是固定速度往上捲（`TeleprompterModel` 裡的 `speed`）。人講話有快有慢，停下來喘口氣，稿子就跑掉了，接著變成人在追稿子，聽起來就是在唸稿。

分兩步做。

第一步很便宜：`SpeechActivityMonitor` 已經在判斷「有沒有在講話」，沒聲音超過一小段時間就讓提詞暫停，一開口再繼續。不用語音辨識，這一輪就能做。

第二步是語音跟隨，稿子跟著你唸到哪捲到哪。要用裝置端語音辨識，有兩件事我現在沒辦法保證，得上真機試：繁體中文的裝置端辨識在目標機型上能不能用，以及辨識要吃的音訊能不能和現在的錄影輸出共用同一條管線。試不過就停在第一步。

### 3. 稿子都寫好了，字幕還要再打一次

台灣的口播短影音幾乎都上字幕。新手錄完之後要嘛丟進剪映自動辨識再逐句改錯字，要嘛放棄不上。

但這個 app 手上本來就有完整的稿。辨識只需要負責「哪句話在第幾秒」，字用稿子裡的，錯字問題少掉一大半。輸出一個 SRT 檔，丟進任何剪輯軟體都能用。直接把字幕燒進影片是更後面的事。

這是我覺得最能跟一般提詞 app 拉開差距的功能，也是三個裡面最難做的，所以排第三輪。它和缺口 2 的語音跟隨吃同一套辨識，真機上驗過一個，另一個就知道能不能做。

### 4. 不知道這篇稿要講多久

各平台的短影音都有長度上限，新手寫稿時沒概念，錄完才發現超時。

做法：稿件頁顯示字數和預估時長（字數除以語速，語速給預設值，可以調），錄影時計時旁邊顯示預估總長。分段之後每段也各自顯示。這是整份清單裡最便宜的一項。

### 5. 手機架遠了，按不到

現在只能靠倒數走回定位，停止的時候還是得走過去按，那幾秒會錄進去。

做法：音量鍵和藍牙自拍遙控器可以開始、停止錄影（iOS 17.2 以上有 `AVCaptureEventInteraction`，專案最低支援是 17.0，舊版本要降級處理）。接片時再自動裁掉每段頭尾的靜音，用現有的音量偵測就夠。

### 6. 講師要的是橫的

客群裡的講師、顧問除了短影音還會錄線上課程和 YouTube 長片，那是橫式 16:9。現在專案鎖直式。

這條我放後面，理由是它會動到整個主畫面的版面，提詞和頭像框都要重排。等直式的流程在真機上穩了再說。

## 建議的順序

| 輪次 | 做什麼 | 為什麼排這裡 |
|---|---|---|
| 第二輪 | 分段錄影＋逐段重錄＋自動接片 | 新手每次錄都會撞到，不需要任何素材 |
| 第二輪 | 停頓時提詞自動等人 | 偵測已經寫好，接上去就有 |
| 第二輪 | 稿件預估時長 | 最便宜 |
| 第二輪 | 音量鍵／遙控器錄影、頭尾自動裁靜音 | 和接片一起做順手 |
| 第三輪 | 語音跟隨提詞 | 要先在真機確認裝置端辨識可用 |
| 第三輪 | 稿件對時輸出 SRT 字幕 | 和語音跟隨共用辨識 |
| 之後 | 陪伴模式 | 要拍素材，效果未驗證 |
| 之後 | 橫式錄影 | 要重排主畫面 |

還是不做的：AI 寫稿、美顏濾鏡、剪輯時間軸、帳號和雲端同步。這些有現成的工具，做了也贏不過。

## 第二輪要先跟你確認的事

分段錄影會改到主畫面的操作：錄完一段之後要有「重錄這段／下一段」，全部錄完才進完成頁。稿子沒有空行的時候就當成一段，行為和現在一樣。

第一輪 README 裡列的四件「待真機確認」還沒有結果（未錄影時讀不讀得到音量、影片方向、4K／60 發熱、藍牙麥克風）。接片會放大方向和音訊的問題，所以第二輪動工前，第一輪最好先裝到手機上跑過一次。
